# 趋势 × 预测合并设计（Outlook）

日期：2026-11-21 · 状态：一期已实现（资产预测 + 页面合并）；二、三期待做

## 1. 目标

- 把 `/trends`（趋势）和 `/forecasts`（预测）合并成一个版面「趋势与预测」：沿用 `/trends` 路由（首页、实验页已有链接不变），`/forecasts/` 通过 Hugo aliases 重定向。
- 覆盖：美股（标普500 / 纳斯达克 / 道琼斯）、A股（上证 / 深证 / 创业板）、港股、黄金、原油、经济（美 / 中）、政治与地缘风险、科技主题（保留现有新闻 z 值）。
- 时间刻度：周（5 个交易日）、月（21）、季度（63）；年度只展示，不作为预测。
- 每张卡片同一张图：历史走势 + 预测扇形区间（p10/p50/p90）+ 上涨概率 + 该模型的历史得分（与基准比）。

## 2. 现状问题

| 问题 | 位置 |
|---|---|
| 只有 104 天本地快照，任何统计模型都缺样本 | `data/trends/daily/` |
| 「综合趋势」方向预测是规则拼的（新闻动量 + 市场动量求和），没有验证依据 | `scripts/trends/forecast.py` |
| 行情概率用 20 日正态近似，σ 估计噪声大；没有季度刻度 | `scripts/trends/market_forecast.py` |
| 图表是 CSS 柱条，没有坐标轴、区间、预测线 | `layouts/trends/list.html` |
| 趋势和预测两页数据互相引用，用户要来回跳 | 两个 layout |

## 3. 算法选择（只选有样本外验证的）

原则：**先设一个很难被打败的基准，模型只有在滚动回测里打败基准才上线展示信号；否则页面直接显示基准并注明「模型未胜出」。**

### 3.1 资产价格（美股 / A股 / 港股 / 黄金 / 原油）

| 组件 | 方法 | 依据 | 用途 |
|---|---|---|---|
| 基准 | 历史均值漂移 + 随机游走 | Goyal & Welch (2008, RFS)：几乎没有预测变量在样本外打败历史均值；M6 竞赛（2022–23）中基准同样难以超越 | 所有资产、所有周期的对照组 |
| 波动率 | HAR-RV（Corsi 2009），用 Parkinson / Garman-Klass 日内振幅代替高频已实现方差 | 样本外通常优于 GARCH，是该领域的标准基准 | 预测区间宽度、扇形图 |
| 方向信号（美股 / 港股 / 黄金 / 原油） | 时间序列动量 TSMOM：12 个月收益符号、按波动率缩放（Moskowitz-Ooi-Pedersen 2012；Hurst-Ooi-Pedersen 2017 回溯至 1880 年） | 指数和商品期货上样本外证据最强；对单资产回归的效果有争议（Huang et al. 2020），所以只作为温和偏移 | 月 / 季度漂移 |
| 方向信号（A股） | 短期反转（周）；中期动量权重设低 | 中国市场短期动量弱或不存在、短期反转显著（Yue-Li-Ruan 2023；Yu-Fung-Leung 2019） | 周漂移 |
| 组合 | 等权预测组合 + Campbell-Thompson 约束（符号不对则置零），再向基准收缩 | Rapach-Strauss-Zhou (2010)：组合预测稳定取得正的样本外 R²；Campbell & Thompson (2008) | 最终 μ |
| 原油补充 | 不变预测（no-change）为基准；二期可加 Baumeister-Kilian 实时 VAR（需 EIA 库存 / 产量数据） | 实时 VAR 在 1–12 个月比不变预测的 MSPE 低最多 25%；期货价格预测并不更好 | 二期 |

输出分布：过滤历史模拟（FHS）——`r_h = σ_h ·（μ_z + e）`，e 取实时残差的经验分布（不假设正态或 t，自然保留厚尾），由此得到 p10/p50/p90 和 P(上涨)。

**不采用**：LSTM / Transformer 自训练模型（样本太短、容易过拟合）；Chronos / TimesFM 零样本模型——2025 年对 94 国日度超额收益的研究中样本外 R² 为负（Chronos −1.37%，TimesFM −2.80%），而且会让 GitHub Actions 依赖 torch。可作为三期的对照实验放在「实验」页。

### 3.2 经济

| 目标 | 方法 | 依据 |
|---|---|---|
| 美国当季 GDP | 直接引用 Atlanta Fed GDPNow 与 NY Fed Staff Nowcast（动态因子模型），不自建 | 两者都是公开、持续发布的 DFM 现时预测 |
| 美国 12 个月衰退概率 | 收益率曲线 probit（10 年 − 3 个月，FRED `T10Y3M`），Estrella-Mishkin 形式 | NY Fed 官方衰退概率模型同款，几十年的样本外记录 |
| 中美数据意外 | 现有金十日历的「公布值 − 预期」标准化后做指数衰减累积（类花旗意外指数） | 已有数据，零新增依赖 |
| 中国 | PMI、社融等月度数据的趋势 + 意外；不做点预测 | 公开数据频率低，点预测不可靠 |

### 3.3 政治与地缘

政治事件没有能从价格序列推出的可靠算法，这里只做**度量 + 概率问题**：

| 组件 | 方法 | 依据 |
|---|---|---|
| 风险水平 | Caldara-Iacoviello 地缘政治风险指数 GPR（月度，官网 CSV）+ Baker-Bloom-Davis 经济政策不确定性指数 EPU | AER 2022：GPR 上升可预测一年内投资下降、下行风险上升 |
| 本站新闻信号 | 保留现有的 30 日基线 z 值，作为 GPR 的高频补充 | 已有 |
| 事件概率 | 二元问题 + Brier 评分；LLM 多次采样取 log-odds 均值、适度外推（extremize） | Good Judgment Project：聚合加外推显著优于简单平均；Halawi et al. 2024：检索增强 LLM 预测接近人群水平 |

## 4. 验证框架（上线门槛）

- 滚动起点回测（walk-forward），2015 年至今，每周一个起点，不偷看未来。
- 指标：方向用 Brier 和 log score；区间用 CRPS、pinball loss、80% 区间实际覆盖率；对基准做 Diebold-Mariano 检验。
- 页面上每个模型都标注**技能分** `1 − Brier_model / Brier_baseline`，并把回测和实盘分开显示。
- 上线规则：Brier 技能分 ≥ 1% 且 DM 单侧 p < 0.05，才显示模型信号；否则显示基准。约 30 个资产×周期同时检验，p < 0.1 会放进约 3 个偶然胜出的模型（初次回测中深证周度技能分仅 +0.3% 却 p=0.084），所以门槛收紧。
- 现有 `market_questions/`、`market_resolutions/` 的追加写入、不覆盖机制保留，新增 `horizon=quarter`。

## 6. 页面

路由 `/trends`（菜单名「趋势与预测」），`/forecasts/` 用 Hugo `aliases` 重定向。页面三块：资产走势预测（#assets）、新闻与话题趋势（#topics）、预测记录（#record）。规则方向判断与情景（rules-v1，无验证依据）不再展示，数据管线保留。

```
[ 周 | 月 | 季 ]  ← 全页共享的时间刻度切换
┌ 资产卡片（美股 / A股 / 港股 / 黄金 / 原油）────────────┐
│ 标普500   6910   P(涨)=54%  区间 −4.1% ~ +5.0%       │
│ ▁▂▃▅▆▇▆▅ ░░▒▒▓▓  ← 历史线 + 预测扇形                 │
│ 技能分 +0.02（回测 520 次）· 模型未胜出时显示「基准」│
└───────────────────────────────────────────────┘
┌ 经济：衰退概率仪表 · GDPNow · 意外指数折线 ──────────┐
┌ 地缘与政治：GPR / EPU 折线 + 本站新闻 z 值 + 概率问题 ┐
┌ 科技主题：保留现有趋势条目（z 值、相关事件）─────────┐
┌ 记录：Brier 对比、校准图、已结算问题表 ─────────────┐
```

图表：内联 SVG，用约 200 行原生 JS 从 JSON 渲染，不引入图表库，沿用现有设计令牌和深色模式。

## 7. 分期

1. **一期**：历史数据抓取 + 基准 / HAR / TSMOM / 反转 / 组合 + 回测 + 合并页面和图表（资产部分）。
2. **二期**：经济（衰退概率、GDPNow、意外指数）+ GPR / EPU。
3. **三期**：政治概率问题的 LLM 聚合；原油 VAR；TSFM 对照实验。

## 9. 一期回测结果（2026-11-21，2012–2026 周度滚动起点）

| 资产 | 周 | 月 | 季度 |
|---|---|---|---|
| VIX（均值回复） | 模型 +4.9%，p=0.001 | 模型 +8.5%，p=0.001 | 模型 +9.9%，p=0.039 |
| 创业板指 | 基准 | 模型 +1.4%，p=0.032 | 基准（+0.8%，p=0.35） |
| 美股三大指数、上证、深证、恒指、黄金、原油 | 基准 | 基准 | 基准 |

- 指数与商品的方向信号基本打不过历史均值，与 Goyal-Welch、M6 的结论一致；美股 2010 年后 12 个月动量回归斜率为负，按 Campbell-Thompson 约束自动关闭。
- 80% 区间实际覆盖率 71%–83%，季度略偏窄（美股 71%–77%）。
- 每个页面概率同步登记为行情问题（新增季度刻度，`model_version: outlook-v1`），到期按实际行情结算并计 Brier。
